Cette erreur indique que Linux a atteint la limite de surveillance de fichiers. Voici comment corriger :

## 🔧 Solution : Augmenter la limite des watchers

```bash
# 1. Vérifier la limite actuelle
cat /proc/sys/fs/inotify/max_user_watches

# 2. Augmenter temporairement (jusqu'au redémarrage)
sudo sysctl fs.inotify.max_user_watches=524288
sudo sysctl -p

# 3. Rendre permanent
echo fs.inotify.max_user_watches=524288 | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```
